Deminsions in each Viewport:
use three css files, one for each view port (index.css, tablet.css andmobile.css)
- index.css: no media query, always loas, targets laptop and desktop with a fixed 960px wrapper.
- tablet.css: only for screen with a width betwee 481 - 1023px
- mobile.css: only for screen with less than 480px

all these stylesheet are linked in every HTML file with the media arrtibute so the browser only loads the correct one.

on laptop, the left and right column sit side byside by usinr the code "float: left/right"

on tablet and mobile, the columns will stack certically by using the code "float: none"

NO FLEXBOX is used in the project


Linear Gradients:
I used an angle linear gradient on the "body" element in two CSS files
    - index.css: background: linear-gradient(135deg, #D99437 0%, #23B7D9 100%);
    - mobile.css: background: linear-gradient(135deg, #D99437 0%, #23B7D9 100%);
both of them uses 135 deg angle, it means diagonal top left to bottom right
